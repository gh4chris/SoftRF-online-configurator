PSRFC command

NMEA control sentence built from the current settings. Send it to your SoftRF device (e.g. via a serial terminal) to store the settings permanently. The checksum is calculated automatically (XOR, NMEA standard).

Decode PSRFC sequence

Paste an existing $PSRFC… command here to verify its checksum and transfer the settings to the selectors above. Afterwards, the generated command in the output panel shows whether it matches the input.

Command format, parameter order and defaults identical to the original tool · one file, no network access, no trackers.
